# 雁笺 UI v2 设计稿

本目录记录“月白青玉”视觉方向的功能页面图稿。它是后续 Android / HarmonyOS 兼容客户端重构的视觉基线，不代表对应页面已经完成代码实现。

## 设计语言

- 内容层：月白底色上的轻量软拟态，使用成对的冷色高光与玉灰阴影表达浅凸、浅凹和按压状态。
- 操作层：底部导航、返回按钮和少量辅助控件使用连续液态玻璃材质，避免把玻璃效果铺满正文区域。
- 品牌色：青玉为主交互色，墨青用于正文，浅玉用于状态背景；朱砂只作为雁喙或极少量警示点。
- 品牌一致性：桌面图标、页首图标与页面 Logo 使用同一个折纸飞雁/信封图形。
- 导航结构：一级导航固定为“记录 / 规则 / 守护 / 设置”；邮箱、后台授权、诊断、迁移与更新归入设置体系。

建议实现色值：

| Token | 色值 | 用途 |
| --- | --- | --- |
| `paper` | `#F4F7F6` | 页面基础底色 |
| `ink` | `#14232B` | 主文字与图标 |
| `jade` | `#4E8D7C` | 主操作与成功状态 |
| `jade-soft` | `#B8D8CF` | 选中背景与折射边缘 |
| `cinnabar` | `#C94B3D` | 品牌微小点睛与高优先级警示 |

## 实现约束

- 软拟态不替代层级结构；列表优先使用分组和分隔线，不为每一行建立独立卡片。
- 所有关键文字和图标必须满足可读性，系统开启“减少透明度”或设备不支持实时模糊时，应回退为高不透明度表面。
- 授权码、真实短信、手机号和诊断敏感信息不得出现在设计资源、截图测试或仓库示例中。
- 页面不得承诺普通应用可以永久后台运行；守护状态必须如实反映权限、网络、SIM 和真实短信闭环结果。
