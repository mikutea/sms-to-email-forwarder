# “厂商后台启动”入口修复审计

审计日期：2026-08-25

目标版本：`1.0.1-beta.1`

测试环境：项目专用 VPS 上的 Android 15（API 35）模拟器

## 结论

入口页在修复前后没有视觉回归。修复版点击“厂商后台启动”后能够进入雁笺的系统应用详情，不再依赖 `resolveActivity()` 的查询结果，也不再调用不稳定的华为隐式 Intent。

模拟器不包含华为系统管家，因此只能验证通用回退链路，不能代替 HarmonyOS 4.x 真机对厂商内部页面的最终验证。

## 对照步骤

1. `01-current-entry.png`：v1.0.0 入口页，视觉状态健康。
2. `02-current-result.png`：v1.0.0 在标准 Android 模拟器上的结果；能够进入应用详情，但无法复现用户设备上的华为专属解析错误。
3. 代码审计：发现旧版先用 `resolveActivity()` 做硬拦截，并使用未公开稳定性的华为隐式 Action；在包可见性或厂商路由差异下可能错误判定“没有应用可执行”。
4. `03-fixed-entry.png`：1.0.1-beta.1 入口页，与旧版保持一致，视觉状态健康。
5. `04-fixed-result.png`：修复版的通用回退结果，完整进入雁笺应用详情，状态健康。

## 修复后的路由

1. 尝试已知的华为系统管家显式页面。
2. 页面不存在或拒绝第三方调用时，直接打开雁笺应用详情。
3. 继续失败时回退到应用列表和系统设置。
4. 所有系统入口均不可用时，显示雁笺玻璃态说明框和手动路径。

普通第三方 App 无法替用户直接开启华为的自启动、关联启动和后台活动开关；本次修复的目标是可靠地把用户送到系统允许访问的最接近页面。
