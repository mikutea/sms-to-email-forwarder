# 后台授权与全量交互审计

审计日期：2026-08-25

目标版本：`1.1.0-beta.2`

环境：独立 Android 15 / API 35 软件渲染虚拟设备；页面按 1080 × 2400、系统动画比例 1× 检查。

## 结论

本轮关闭了厂商后台设置“去了系统页、返回却无法确认”的核心断点。短信权限与忽略电池优化继续直接使用系统确认框；厂商的自启动、关联启动和后台活动没有 Android 标准授权接口，改为“打开最接近的系统页 → 返回雁笺立即确认 → 进入真实锁屏试投”的诚实闭环。

系统守护进度由错误的四项计数改成三项真实前置设置，网络只显示实时状态。重复路由、错误修复入口、无响应帮助按钮、模糊 Toast、触控区域和状态色对比度问题已经一并整改。未发现新的空白页面或同一按钮复用错误目标。

## 设计与无障碍整改

- 主动作使用更深的青玉渐变，白字与最亮渐变色的对比度约为 `4.6 : 1`；琥珀状态文字调整后在月白背景约为 `4.9 : 1`。
- 按钮、输入框、下拉框、开关、时间与星期控件、帮助图标和可点状态行均按缩放后的至少 48 dp 目标整改。
- 所有图标按钮增加可读的辅助功能描述；装饰箭头从无障碍树中移除。
- 动效继续使用短时透明度、位移和轻微缩放，并遵循系统“移除动画/减少动画”设置；不增加持续背景动画或实时全屏模糊。
- 一级页面在当前 Activity 内缓存；返回已打开的一级页面不再重建整棵玻璃卡片视图，导航只动画新旧两个选中项。软件渲染模拟器的缓存导航 `99th percentile` 由整改前约 `500 ms` 降到约 `101 ms`，但该环境仍不能代表真机 GPU 帧率。

无障碍树与尺寸可以在模拟器中自动检查，但屏幕阅读器语速、触觉反馈、华为字体替换和单手误触仍需真机人工验收。

## 仍然存在的系统边界

- 普通第三方 App 不能直接弹出或自动修改华为自启动、关联启动、后台活动三个开关，也无法可靠读取它们的状态。
- API 35 通用模拟器没有华为系统管家，只能验证显式入口、应用详情回退和返回确认，不能替代 HarmonyOS 4.x 真机的最终页面验证。
- 软件渲染模拟器可验证布局、路由和基本动画时序，不能代表真机 GPU 动画手感；长时锁屏、SIM/基带、移动网络和真实 SMTP 仍须在用户设备完成。
