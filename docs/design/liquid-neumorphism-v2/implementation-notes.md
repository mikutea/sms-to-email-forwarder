# UI v2 原生实现说明

## 页面结构

一级导航固定为“记录 / 规则 / 守护 / 设置”。邮箱通道、系统守护、维护诊断与后台授权引导是设置体系的二级页面，返回后继续保持“设置”选中状态。

## Motion 规范

| 类型 | 时长 | 用途 |
| --- | --- | --- |
| Quick | 140 ms | 按钮按下反馈 |
| Standard | 220 ms | 按钮回弹、导航选中 |
| Emphasized | 300 ms | 页面进入、内容展开与收起 |

- 动画只使用透明度、位移和缩放等合成友好属性，不在交互期间执行网络、数据库或位图处理。
- 页面进入动画作用于屏幕大小的滚动视口，不把超长表单整体提升为硬件纹理。
- 系统关闭动画或启用相应无障碍偏好时，所有装饰动画立即降级为最终状态。
- 不使用实时全屏背景模糊；低版本与厂商系统统一使用高不透明度玻璃表面，避免 GPU 负载和文字可读性波动。

## 可访问性与兼容

- 主要按钮和底部导航满足至少 48 dp 触控高度。
- 图标与状态不能成为唯一信息来源，关键状态同时提供中文文字。
- Android 6.0–8.0 使用基础浅色导航栏；浅色导航栏图标属性仅在 API 27 及以上资源中启用。
- 界面仍保持 `FLAG_SECURE`，SMTP 授权码与短信正文不会进入系统截图或最近任务缩略图。

## 验证边界

JVM 单元测试、Android Lint、Debug APK 和 Release APK 构建用于验证代码与资源完整性。动画帧率、锁屏后台可靠性和不同厂商字体/导航栏表现仍必须在受支持的真实设备上复验。
