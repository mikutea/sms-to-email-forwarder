# 华为 HarmonyOS 4.x 真机设置

本指南适用于仍可安装 Android APK 的华为设备；不同机型和系统版本的设置名称可能不同。

## 安装后设置

1. 打开“雁笺”，填写 SMTP 配置并先发送测试邮件。
2. 点击“启用自动转发”，允许“短信”权限。
3. 在“系统守护”点按“忽略电池优化”，在系统弹窗中确认允许。
4. 点按“厂商后台启动”。雁笺会尽量打开最接近的系统页；找到“应用启动管理”后改为手动管理，并允许自动启动、关联启动和后台活动。
5. 返回雁笺时会立即出现确认框；只有三个开关确实已允许时才点“已全部允许”。如果系统页不是目标页，可点“继续设置”或从应用详情进入耗电详情/应用启动管理。
6. 进入“锁屏试投”，分别在亮屏、锁屏、Wi-Fi 和移动网络环境下发送真实测试短信。
7. 完成真实短信闭环后，再开启旅行守护。

不同 HarmonyOS 4.x 补丁版本的设置名称可能略有差异，应以真机显示为准。

> 华为没有向普通第三方 App 提供稳定、公开的自启动、关联启动和后台活动授权接口，也不提供可靠的开关状态回调。因此这三项不能像短信权限一样由雁笺直接弹出标准授权框或自动勾选；雁笺只能打开系统页、在返回时让用户确认，并通过真实锁屏短信闭环验证最终效果。

## 验收条件

- App 关闭且锁屏时，新短信仍能进入待发送队列并投递。
- 多段长短信合并为一封邮件。
- 断网收到短信后，恢复网络能自动补发。
- 同一条系统广播重复到达时，不创建重复队列项。
- SMTP 认证失败时正文仍保存在本机加密队列，状态页不暴露授权码和正文。
- 启用验证码过滤后，包含验证码关键词和 4–8 位数字的短信不会外发。

仅看到测试邮件成功不代表实时转发验收完成；必须在实际使用设备上完成上述真实短信测试。

完整场景和长时测试见 [旅行守护与真机验收](travel-mode.md)。
