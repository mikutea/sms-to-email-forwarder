# 雁笺 0.3.0-beta.2

这是用于真实设备验收的预发布版本，不是稳定版。

## 本次变化

- 修复后台转发任务在内部续排时取消自身的问题，失败短信可以稳定进入后继重试任务。
- Debug 测试包允许截图以支持视觉回归；正式 Release 构建仍禁止系统截图。
- 完成 Android 15 / API 35 虚拟设备回归，覆盖普通短信、验证码过滤、加密队列、锁屏进程回收及系统重启恢复。
- 调整设置页隐私说明，使本机加密范围表述更加准确。

## 验证与限制

- JVM 单元测试、Android Lint、Debug/Release APK 构建和 GitHub Actions 已通过。
- 此公开资产是 Debug 签名测试包；若旧测试包签名不同，需要先卸载旧包。卸载会清除旧配置、队列和历史。
- 厂商省电策略、自启动管理、真实 SIM/基带、真实 SMTP 及多日锁屏仍需在用户自己的设备上验收。
- 请勿在公开反馈中上传真实短信、手机号、邮箱授权码、设备标识或签名材料。
