# 雁笺 1.0.0

首个正式版本，面向 Android 6.0 及以上，以及保留 Android APK 兼容能力的 HarmonyOS 2/3/4 华为设备。

## 主要能力

- 新短信直连用户自己的 TLS SMTP，不依赖项目中继服务器。
- 本机加密队列、断网补发、主备 SMTP、多收件人和规则路由。
- 旅行守护、后台授权引导、健康心跳、加密历史和脱敏诊断。
- 短信与电池优化使用单应用系统确认，返回后自动复核；厂商启动管理提供可靠入口与明确边界。
- 稳定版 / Beta GitHub Release 更新通道；后续版本使用同一正式签名，可覆盖安装并保留本机配置。
- SMTP 加密方式与推荐端口自动联动，加入飞书邮箱预设和可执行的错误分类。
- 正式 APK 提供 SHA-256、签名证书、CycloneDX SBOM 和 GitHub 构建来源证明。

## 从旧测试版升级

早期测试 APK 使用临时调试签名，与正式版签名不一致。Android 不允许跨签名覆盖安装，因此从旧测试版迁移到 1.0.0 需要最后一次卸载；可先导出无密码配置，安装正式版后导入并重新填写一次授权码。自 1.0.0 起，正式版和后续 Beta 均使用同一签名，不再需要重复卸载或重填配置。

## 平台边界

HarmonyOS NEXT 普通第三方应用没有本项目所需的公开系统新短信读取能力，因此 1.0.0 不宣称支持 NEXT 自动短信转发。
