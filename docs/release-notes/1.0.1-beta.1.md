# 雁笺 1.0.1-beta.1

这是面向 HarmonyOS 4.x 后台启动设置入口的兼容性测试版。

## 修复

- 修复点击“厂商后台启动”后可能提示没有应用可执行的问题。
- 移除不稳定的华为隐式 Intent，依次尝试兼容的显式入口。
- 厂商页面不可访问时，直接打开雁笺应用详情；再不可用时依次回退到应用列表和系统设置。
- 所有系统入口均失败时显示雁笺自己的说明框，并给出完整手动路径。

## 说明

华为没有向普通第三方 Android App 提供稳定、公开的“应用启动管理”授权接口。若进入的是雁笺应用详情，请继续打开“耗电详情”或“应用启动管理”，允许自启动、关联启动和后台活动，然后返回雁笺确认完成。
