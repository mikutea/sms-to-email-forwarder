# 雁笺 1.1.0-beta.1

这是首个支持安全应用内更新的测试版。

## 新功能

- 在雁笺内直接下载正式版或 Beta APK，显示进度并支持取消和失败重试。
- 下载完成后自动校验资产大小、SHA-256、包名、版本号、递增版本代码和雁笺正式签名。
- Android 8 及以上首次使用时引导开启“允许来自此来源”，返回雁笺后自动继续打开系统覆盖安装确认。
- 覆盖安装继续保留 SMTP 配置、规则、加密队列和历史；系统最终安装确认不能由普通 App 绕过。

## 安全边界

更新器只接受 `mikutea/sms-to-email-forwarder` 官方 GitHub Release 中与标签严格匹配的 APK。下载文件保存在应用私有缓存，通过受限内容 URI 临时交给系统安装器；雁笺不能静默安装，也不会下载或安装其他包名的应用。

这是第一次加入更新器，因此从 `1.0.x` 安装本版本仍需要手动下载一次。从本版本开始，后续更新即可在 App 内完成下载、校验和安装引导。
