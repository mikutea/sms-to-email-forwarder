# 雁笺 1.1.0-beta.2

这是一次面向后台授权与旅行守护操作闭环的交互修复版，可从 `1.1.0-beta.1` 在应用内覆盖安装，原有邮箱配置、规则、队列与历史会保留。

## 改进

- 从厂商后台设置返回后立即询问是否已允许自启动、关联启动和后台活动，不再要求用户另找隐藏确认项。
- 系统守护只统计三项真实前置设置；网络单独显示实时状态。
- 新增“锁屏试投”最后一步，用真实短信分别验证自动转发、短信接收和邮件投递。
- 修正多个按钮落到相同或错误页面的问题，并为 SMTP、规则和心跳错误提供直接修复入口。
- 扩大关键触控区域，提高琥珀状态文字、朱砂提示和青玉主按钮的对比度。
- 复用已经构建的一级页面，并只动画底部导航中真正变化的选中项，降低重复布局和合成开销。

## 系统边界

短信权限与忽略电池优化可以由雁笺直接显示系统确认。华为厂商的自启动、关联启动和后台活动没有公开稳定的标准授权框或状态 API，雁笺不能替用户自动勾选；本版会打开最接近的系统页、在返回时立即确认，并以真实锁屏短信作为最终验收。

普通 App 不能绕过 Android 的覆盖安装确认。Beta 与稳定版使用同一正式签名，因此确认安装后可保留本机数据。
