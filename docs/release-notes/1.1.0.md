# 雁笺 1.1.0

这是雁笺的第二个正式版本，重点补齐开源信息、短信邮件可读性和设置页导航层级，并整合此前 Beta 中的应用内安全更新与后台授权交互。

## 本版变化

- 邮件升级为 HTML + 纯文本双格式，在手机邮箱中清晰显示发送方、时间、SIM、正文和投递编号。
- SMTP 自检、短信、旅行守护心跳与设备提醒使用不同主题，便于在邮箱中筛选。
- 新增“设置 → 关于雁笺 → 开源许可”，离线提供 Apache-2.0 完整文本和第三方组件清单。
- 设置页按任务重组；平台边界、开源许可、版本更新均归入“关于雁笺”。
- 设置子页隐藏一级底部导航，页面按钮、Android 返回键和返回手势均逐级返回当前可见父页面。
- 邮箱配置页新增邮件样式预览。
- 支持稳定版 / Beta 通道、应用内下载、摘要/包名/版本/签名校验与系统覆盖安装确认。
- 权限设置返回后立即复核；厂商启动管理返回后使用一次明确确认，不再让用户寻找额外隐藏勾选项。

## 安装

可直接覆盖安装 `v1.0.0` 或同签名 Beta，本机邮箱配置、规则和历史记录会保留。Android 8 及以上首次使用应用内更新时，系统可能要求允许雁笺安装未知应用；最终覆盖安装仍需用户在系统确认页点按确认。

## 平台边界

- 支持 Android 6.0（API 23）及以上。
- 兼容 APK 的 HarmonyOS 设备可使用同一 APK，但需针对具体设备完成后台与锁屏真机验收。
- HarmonyOS NEXT 普通三方应用没有公开的短信读取能力，本版不宣称支持 NEXT 自动短信转发。

## 验证

- 39 项 JVM 单元测试、Android Lint、Debug/Release 构建通过。
- Android 15 / API 35 隔离虚拟设备完成两级返回、底部导航、130% 字号、减少动画、邮件预览和开源许可页面回归。
- 真实 SIM、真实 SMTP、厂商后台管理和多日锁屏稳定性仍需在目标真机上完成最终验收。
