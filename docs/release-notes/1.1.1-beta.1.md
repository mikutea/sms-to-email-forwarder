# 雁笺 v1.1.1-beta.1

这是面向移动网络 SMTP 失败诊断与三项界面反馈的修复测试版。

## 主要变化

- 更准确地识别移动网络、互联网验证状态和后台流量限制，并提供雁笺专属流量设置入口。
- SMTP 失败记录显示不含凭据和服务器原始响应的诊断码，便于区分认证、TLS、DNS、超时、系统阻断、无路由和连接中断。
- 延长 SMTP 连接、读取和写入超时，降低移动网络短时抖动造成的误失败。
- 删除守护主页右上角“退出向导”。
- SMTP 授权码支持点按眼睛图标显示或隐藏，默认仍为隐藏状态。
- 关于页移除重复 Logo。

## 验证边界

本版已在项目隔离测试环境完成单元测试、静态检查、构建和 Android 15 / API 35 虚拟设备交互回归。运营商端口策略、HarmonyOS 厂商后台限制、真实短信广播与长时锁屏转发仍需使用实际设备验证。
