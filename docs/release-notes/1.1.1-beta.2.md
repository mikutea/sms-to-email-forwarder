# 雁笺 v1.1.1-beta.2

这是修复移动网络下 SMTP 失败诊断和守护状态误判的测试版。

## 主要变化

- 继续追踪 JavaMail 的下一层异常，连接重置、超时、认证失败和服务器提前断开会显示更具体的脱敏诊断码。
- 识别常见 SMTP 4xx / 5xx 返回码；诊断信息不会包含授权码或服务器原始响应。
- SMTP 状态改为“已配置 / 已验证 / 验证失败”，不再把参数填写完整误显示为“SMTP 已连接”。
- 最近一次 SMTP 验证失败后，守护页显示“守护需处理”，旅行守护同步标记“需处理”。
- 点按守护状态卡可查看原因，并直接进入邮箱配置页重新测试。

## 建议验证

安装后请分别在 Wi-Fi 和移动数据下点按“测试主通道”。若仍失败，请提供界面显示的诊断码即可，不要发送授权码或完整服务器响应。

## 验证边界

本版已在项目隔离测试环境完成单元测试、静态检查、构建和 Android 15 / API 35 虚拟设备失败态回归。虚拟设备无法模拟具体运营商端口策略、APN、HarmonyOS 厂商后台限制和真实蜂窝基带，移动数据实网结果仍需真机确认。
