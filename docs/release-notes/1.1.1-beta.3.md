# 雁笺 v1.1.1-beta.3

这是修复 Beta 2 测试邮件闪退的紧急测试版。

## 修复内容

- 修复 SMTP 失败诊断初始化时的 Android / HarmonyOS 正则兼容问题。
- 点按“测试主通道”或“测试备用通道”后，即使 SMTP 返回认证、网络或服务器错误，应用也会保持运行并显示脱敏诊断结果。
- 保留 Beta 2 的“已配置 / 已验证 / 验证失败”状态和 JavaMail 下一层异常诊断。

## 验证

- Android 设备端回归测试已确认旧实现必现 `ExceptionInInitializerError`，修复后通过。
- Android 15 / API 35 虚拟设备已完成真实点击测试，SMTP 失败后应用进程保持运行，未出现 `FATAL EXCEPTION`。
- JVM 单元测试、Android Lint、Debug/Release 构建均需通过发布流水线后才会生成签名 APK。

安装时可直接覆盖 Beta 2，不需要卸载，现有本机配置会保留。
