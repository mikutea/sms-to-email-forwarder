# 雁笺 1.1.1 Beta 4

发布日期：2026-08-28

这是用于真实设备 SMTP 故障闭环的测试版本，可从 Beta 3 直接覆盖安装，现有邮箱配置、规则和本地记录会保留。

## 本次更新

- SMTP 测试明确记录“连接/认证”或“提交邮件”阶段，减少笼统的协议错误。
- 识别读取响应、异常问候语、写命令失败以及 JavaMail SMTP 扩展异常中的 4xx/5xx 返回码。
- 诊断内容严格脱敏，只包含预定义信号和异常类型，不保存授权码、邮箱地址或服务器原始响应。
- 保留 Beta 3 的 Android/HarmonyOS 测试邮件闪退修复。

## 安装与反馈

1. 直接覆盖安装，不要卸载旧版本。
2. 在“邮箱通道”中点击“测试主通道”。
3. 如果仍失败，打开守护状态卡查看新的“阶段 / 线索 / 异常”诊断；无需提供授权码。

本版本仍是预发布版本。正式稳定性结论需要在真实 Wi-Fi、移动数据、真实短信和锁屏后台环境完成闭环验收。
