# 雁笺 1.1.1 Beta 5

发布日期：2026-08-28

这是针对 Android/HarmonyOS 正式包多格式邮件发送失败的修复版本，可从 Beta 4 直接覆盖安装，现有邮箱配置、规则和本地记录会保留。

## 修复内容

- 修复签名 Release APK 在连接和认证成功后，提交 HTML + 纯文本邮件时出现 `UnsupportedDataTypeException` 的问题。
- 显式注册 JavaMail 的纯文本、HTML、多段邮件和 RFC 822 内容处理器。
- 保证 R8 压缩不会删除由 Mailcap 动态加载的处理器类。
- CI 和签名发布流水线新增 Release DEX 检查，缺少处理器时直接阻止构建和发布。
- 保留 Beta 4 的分阶段脱敏诊断和 Beta 3 的测试邮件闪退修复。

## 验证边界

本版本会在真实 HarmonyOS 4.2 设备上继续验证 Wi-Fi、移动数据和真实 SMTP 投递。短信广播、锁屏后台补发及厂商后台策略仍需分别完成真机闭环。
