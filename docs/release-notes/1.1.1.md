# 雁笺 1.1.1

发布日期：2026-08-31

这是雁笺 1.1 系列的稳定更新，汇总此前 Beta 已验证的队列可靠性、SMTP 兼容性、应用内更新、后台授权、可选短信已读联动和本地自然日成功统计。它与既有正式版和 Beta 使用同一包名与签名，可以直接覆盖安装并保留本机数据。

## 主要变化

- “今日成功”改为按手机当前时区的本地自然日和 SMTP 首次接受时间统计，不再误用最近 50 条历史记录，也不受详细历史容量裁剪影响。
- 首次 SMTP 接受时间和已投递通道位持久保存；本机终态稍后重试或跨过午夜时，不会重复发送或把成功移动到另一天。
- 待发队列加入紧急短信调度、自愈唤醒、分类容量与心跳合并；网络恢复、应用更新和设备重启后会重新核对持久队列。
- 修复压缩 Release 构建中 JavaMail 多格式邮件处理器被裁剪的问题，正式包可以稳定发送 HTML 与纯文本双格式邮件。
- SMTP 诊断区分连接、认证和提交邮件阶段，只保存脱敏诊断码，不保存服务端原始响应或凭据。
- 增加主备 SMTP、应用内安全下载与覆盖更新、无密码配置迁移、开源许可、统一设置层级和后台授权引导。
- 可选“成功后标记系统短信已读”默认关闭；只调用默认短信应用提供的语义明确标准动作，没有安全动作时保持原状并给出明确结果。

## 安装与升级

可以直接覆盖安装 `v1.1.0`、`v1.1.1-beta.1` 至 `v1.1.1-beta.8`，无需卸载。覆盖安装会保留：

- 邮箱服务器、收件人和本机加密的 SMTP 授权码；
- 转发规则、SIM 选择和过滤设置；
- 短信权限、通知权限、电池白名单和厂商后台启动确认；
- 旅行守护、状态心跳、待发队列、转发历史与成功统计。

Android 8 及以上首次使用应用内更新时，系统可能要求允许雁笺安装未知应用；最终覆盖安装仍由系统展示目标应用、签名与用户确认界面。

## 真机闭环

签名候选版本已经在 Android 兼容的 HarmonyOS 4.x 实际设备上完成保留数据覆盖安装和锁屏真实短信闭环：

1. 手机保持安全锁屏；
2. 真实运营商短信触发后台任务；
3. 短信进入本机加密队列并通过用户配置的 SMTP 发送；
4. 收件邮箱收到邮件；
5. 待发数量回到 0；
6. “今日成功”准确增加一次；
7. 未发生重复投递、统计漂移或应用闪退。

默认短信应用没有持续提供可安全调用的标准“标记已读”动作，因此系统短信可能继续显示未读。这不影响邮件转发成功；雁笺不会使用 Root、无障碍模拟点击、默认短信应用身份或私有接口绕过该边界。

## 自动化验证

- 82 项 JVM 单元测试通过；
- Android 15 / API 35 隔离虚拟设备 42 项测试通过；
- Android Lint 0 错误，保留 2 个既有兼容性警告；
- Release/R8 构建和邮件处理器硬校验通过；
- 签名发布工作流会再次校验版本、标签、正式证书、APK 签名、SHA-256、CycloneDX SBOM 和 SLSA 构建来源证明。

## 平台边界

- 支持 Android 6.0（API 23）及以上。
- 保留 Android APK 兼容能力的 HarmonyOS 设备可使用同一 APK，但厂商后台策略仍需按设备完成设置。
- HarmonyOS NEXT 不直接运行本 APK，普通第三方应用也没有可用于自动读取系统短信的公开能力；本版不宣称支持 NEXT 自动短信转发。
