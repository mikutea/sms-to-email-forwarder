# 旅行守护与真机验收

旅行守护不是“常驻进程”开关。普通 Android 应用无法承诺永不被系统回收；雁笺依靠系统短信广播快速入队、WorkManager 联网发送、加密持久队列和用户完成的华为后台授权来提高长期可靠性。

## 开启门槛

App 仅在以下条件全部满足后允许开启旅行守护：

- 已授予接收新短信权限；
- 自动转发已启用；
- SMTP 配置有效且网络可用；
- 已关闭该应用的电池优化限制；
- 用户确认已完成华为应用启动管理设置；
- 至少一条真实短信已经成功转发，而不只是 SMTP 测试邮件成功。

“系统守护”的 `3 / 3` 只统计短信权限、忽略电池优化和厂商后台启动确认；网络是实时状态，不会被伪装成一项授权。完成这三项后仍需进入“锁屏试投”，用真实短信验证接收、入队和邮件投递三段闭环。

## 离家前测试矩阵

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 亮屏 | 前台/后台各收一条短信 | 邮件正文、发件人、时间和卡槽正确 |
| 锁屏 | 清除 App 界面后锁屏 30 分钟再收短信 | 无需重新打开 App 即可投递 |
| Wi-Fi/移动网络 | 两种网络各收一条 | 均能投递，状态无持续失败 |
| 断网恢复 | 断网收短信，至少 2 分钟后联网 | 队列保留且自动补发 |
| 重启 | 重启并首次解锁后收短信 | 自动转发和心跳计划恢复 |
| 多段短信 | 发送超过一条短信长度的内容 | 合并为一封邮件，不重复 |
| 双卡 | 分别向 SIM 1/2 发短信 | 卡槽识别和规则符合设置 |
| 长时 | 锁屏充电运行 24–72 小时 | 心跳持续到达，真实短信仍可投递 |

每次系统大版本升级、App 更新、权限重置或系统管家清理后都应重新执行锁屏与断网测试。项目公开记录只保留设备类别、系统大版本和合成测试结论，不记录个人设备的具体型号或标识符。

## 心跳边界

可选择每 6、12 或 24 小时发送一封设备健康摘要。Android 的周期任务为节能会有时间漂移，心跳用于发现异常，不是精确闹钟。长时间未收到心跳时，应让可信人员检查手机电量、网络、SIM 服务和应用权限。
